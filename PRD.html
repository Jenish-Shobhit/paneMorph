Requirements

Product contract

All items below are required for the first open-source release.

Live-process preservation

Moving a pane preserves its process, working directory, terminal state, scrollback, title, and detected agent session.

Two-key maximum

Every default shortcut uses one key or a modifier plus one key. No default requires three simultaneous keys or a prefix sequence.

No automatic overwrite

Installation proposes the shortcut preset, detects collisions, and asks before changing Herdr configuration.

Keyboard-first selectors

Search, arrows, Enter, and Esc are sufficient. Mouse support is useful but not required for v1.

Safe complex moves

Capture layouts, preflight every pane, execute deterministically, verify the result, and attempt rollback on partial failure.

Local and private

No network requests, accounts, analytics, telemetry, or hosted service. The plugin talks only to the active Herdr server.

Shortcut preset

One modifier, one key

These are proposed defaults, not hard-coded behavior. Users may rebind every action.

Open source

Repository and implementation plan

The public project should be understandable, installable, and testable without hidden services.

Identity

Project: paneMorph
Repository: herdr-paneMorph
Plugin ID: dev.panemorph
License: MIT

Package

Herdr manifest, action commands, terminal selector, configuration assistant, tests, README, architecture guide, contributing guide, security policy, code of conduct, and changelog.

Implementation boundary

Use only Herdr’s documented tab, pane, layout, focus, popup, notification, and plugin-action interfaces. No terminal scraping for layout decisions.

Initial support

macOS and Linux in v1. Windows follows after keyboard encoding and selector behavior are verified there.
